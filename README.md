# Friendly Player

Локальный музыкальный плеер: вставляешь ссылку на YouTube, YouTube Music или плейлист Яндекс Музыки — треки
появляются в библиотеке и играют сразу, без скачивания. Нужные можно скачать для прослушивания без интернета.
Тексты песен подсвечиваются вместе с музыкой. Всё работает у тебя на компьютере: без аккаунтов и серверов.

## Приложение для Windows

Проще всего поставить готовое приложение: **[скачать последнюю версию](https://github.com/stxpan/friendly-player/releases/latest)**
(файл `Friendly-Player-Setup-x.y.z.exe`, остальные файлы в релизе нужны для автообновлений).

- Установщик не подписан, поэтому Windows покажет «Windows защитила ваш компьютер» — нажми
  **Подробнее → Выполнить в любом случае**.
- Обновления приходят сами: плеер скачивает новую версию в фоне и ставит её при перезапуске.
- В приложении есть то, чего нет в браузере: сворачивание в трей, глобальные горячие клавиши
  `Ctrl+Shift+A` / `Ctrl+Shift+D` (предыдущий / следующий трек из любой программы) и автообновления.
- Библиотека, музыка и настройки хранятся в `%APPDATA%\Friendly Player`.

Версии для macOS и Linux нет — там плеер можно запустить из исходников в браузере (см. ниже).

## Возможности

- **Добавление по ссылке**: видео и плейлисты YouTube, плейлисты Яндекс Музыки (треки находятся на YouTube
  Music). Можно сразу добавлять в нужный плейлист.
- **Онлайн и офлайн**: треки играют потоком; любой можно скачать, есть «Скачать всё». Без интернета
  играют только скачанные.
- **Поиск** по библиотеке и YouTube Music сразу: прощает знаки препинания, порядок слов и неправильную
  раскладку, результаты YouTube Music подгружаются при прокрутке.
- **Плейлисты**, свой порядок перетаскиванием, сортировки, перемешивание (недавно слушанное — в конец),
  повтор трека или списка, «играть следующим».
- **Радио** по любому треку — бесконечная подборка похожих от YouTube Music.
- **Тексты песен** с подсветкой текущей строки (LRCLIB, YouTube Music). Если у песни есть только текст без
  тайминга, плеер расставляет строки по времени сам — локальной нейросетью (необязательно, модель 364 МБ
  скачивается по желанию).
- **Выравнивание громкости** скачанных треков (EBU R128).
- **Статистика** прослушиваний, подборки «Часто слушаю», «Давно не слушал», «Ни разу не слушал», поиск
  дубликатов.
- **Горячие клавиши** (список в настройках) и медиаклавиши клавиатуры.
- **Настройки**: папка с музыкой, освобождение места (давно не слушанное снова играет онлайн), число
  одновременных загрузок, обновление yt-dlp из интерфейса.

## Запуск из исходников (в браузере)

Работает на Windows, macOS и Linux. Плеер откроется в браузере, данные хранятся в папке проекта.

### Что нужно

- [Node.js](https://nodejs.org/) 24 (нужен встроенный `node:sqlite`).
- [pnpm](https://pnpm.io/installation).
- [ffmpeg](https://ffmpeg.org/download.html), доступный в `PATH`: на Windows — `winget install Gyan.FFmpeg`,
  на macOS — `brew install ffmpeg`, на Linux — из пакетного менеджера.
- На macOS и Linux — Python 3.9 или новее: yt-dlp для этих систем — Python-программа (на Windows ставится
  отдельный `.exe`, Python не нужен).

### Установка и запуск

```sh
git clone https://github.com/stxpan/friendly-player.git
cd friendly-player
pnpm install --filter server --filter web
pnpm dev
```

`--filter` ставит только сервер и интерфейс — Electron (~100 МБ) для браузера не нужен.

Если на Windows нет Python, `pnpm install` остановится на проверке Python. Она там не нужна (yt-dlp ставится
готовым `.exe`) — пропусти её перед установкой:

```powershell
$env:YOUTUBE_DL_SKIP_PYTHON_CHECK = '1'   # PowerShell
set YOUTUBE_DL_SKIP_PYTHON_CHECK=1        # cmd
```

Открой **http://localhost:5174**. Сервер работает на порту 3001; другие порты можно задать через
`WEB_PORT` и `API_PORT` (для сервера — `PORT`).

- Библиотека, база и скачанная музыка — в `server/data` (не попадает в git).
- Плеер слушает только этот компьютер. Доступа с телефона или из сети пока нет, паролей тоже.

## Технологии

| Часть | Что используется |
|---|---|
| Интерфейс (`web/`) | React 19, TypeScript, Vite, Tailwind CSS 4, shadcn/ui, TanStack Virtual, dnd-kit |
| Сервер (`server/`) | Node.js, Hono, SQLite (`node:sqlite`) |
| Музыка | yt-dlp (поток и скачивание), youtubei.js (поиск и радио YouTube Music), API Яндекс Музыки (плейлисты), ffmpeg |
| Тексты | LRCLIB, тексты YouTube Music, синхронизация — ONNX Runtime и модель Meta MMS-300M (forced alignment) |
| Приложение (`desktop/`) | Electron, electron-builder (установщик NSIS), electron-updater (обновления из GitHub Releases) |

## Сборка установщика

Нужна полная установка, вместе с Electron, и Windows:

```sh
pnpm install                            # без --filter: ещё и Electron со сборщиком
node desktop/scripts/fetch-ffmpeg.mjs   # один раз: LGPL-сборка ffmpeg для приложения
pnpm --filter desktop dist              # desktop/dist: установщик, latest.yml и .blockmap
```

Выпуск новой версии: поднять `version` в `desktop/package.json`, закоммитить и выполнить
`pnpm --filter desktop release` с токеном GitHub в `GH_TOKEN` — релиз создастся и файлы загрузятся сами.
